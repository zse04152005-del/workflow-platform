# Workflow Platform 0.1.0 MVP

This release packages the validated DSL/definition baseline, tenant/RLS
database, runtime state transition and trigger kernel, reliability contracts,
security boundaries, human-task model, management console, observability
artifacts and deployment manifests.

Known limits: Kafka/Keycloak/MinIO smoke and 30-minute performance numbers must
be generated in the target environment before production sizing. HTTP connector
providers and KMS/Vault are ports with local-safe implementations. AI remains a
drafting assistant and cannot publish or execute a workflow.
